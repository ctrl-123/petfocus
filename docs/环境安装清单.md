## 二、安装步骤

> **目标路径**（需求方指定，与 VS Code 的 `D:\Apps` 并列，保持整机结构一致）：
> ```
> D:\APP\git\      ← Git
> D:\APP\pnpm\     ← pnpm（独立版，单个 exe）
> ```
> ⚠️ 注意：`winget` 在本项目的沙箱内无法调用，因此**不提供 winget 命令**（无法验证的命令不写进文档）。
> 下面全部是「浏览器下载 + 手动指定路径」的方式，安装向导本身就支持自定义目录。

### 步骤 1：Git → 装到 `D:\APP\git`

1. 下载：https://git-scm.com/download/win → 选 **64-bit Git for Windows Setup**
2. 安装向导走到 **"Select Destination Location"** 时，把路径改为：

   ```
   D:\APP\git
   ```

3. 其余选项保持默认，一路 Next 完成。
4. **关掉终端重新打开**（让 PATH 生效），验证：

   ```powershell
   git --version
   ```

   若提示找不到命令 → 把 `D:\APP\git\cmd` 加进用户变量 `Path`。

### 步骤 2：pnpm → 装到 `D:\APP\pnpm`

**为什么不用 `corepack`**：corepack 只能把 pnpm 装在 Node 自己的目录里，无法指定独立路径。要放到 `D:\APP\pnpm` 必须用官方独立版。

1. 下载（二选一，国内建议第二个）：

   | 源 | 链接 |
   |---|---|
   | 官方 GitHub | `https://github.com/pnpm/pnpm/releases/latest/download/pnpm-win32-x64.zip` |
   | 国内镜像（版本与本文档一致） | `https://registry.npmmirror.com/-/binary/pnpm/v9.15.4/pnpm-win32-x64.zip` |

2. 解压后，让最终结构为（目录里只有一个 `pnpm.exe`）：

   ```
   D:\APP\pnpm\pnpm.exe
   ```

3. 把 `D:\APP\pnpm` 加进用户变量 `Path`，关掉终端重开，验证：

   ```powershell
   pnpm -v
   ```

> **版本说明**：本文档原来写的是 pnpm 9.x，但 pnpm 已发布到 v12。
> **按你能下到的版本装即可，不要为凑版本折腾**；装完把版本号告知，我会调整项目里的 `packageManager` 字段以兼容。
> 若用上面第二个链接，则正好是 9.15.4，与文档一致。

### 兜底方案：两个都下不动时

用已有的 npm 把 pnpm 装进仓库内部（不写系统目录）：

```powershell
cd D:\张鑫\Documents\PetFocus
npm install -g pnpm --prefix .\.tools
```

pnpm 会落在 `D:\张鑫\Documents\PetFocus\.tools`，调用全路径 `.\.tools\pnpm.cmd` 即可。
缺点是不在你指定的 `D:\APP\pnpm`，但完全在仓库内、随时可删，不影响开发。

### 步骤 3：⚠️ 确认 PATH（关键，很多人卡在这里）

你机器上这几个目录**可能不在 PATH 里**，会导致「明明装了却提示找不到命令」：

| 目录 | 用途 | 现状 |
|---|---|---|
| `D:\APP\Node.js\intall` | `node` / `npm` | 已在 PATH（实测可用） |
| `D:\APP\git\cmd` | `git` | 装 Git 后需确认 |
| `D:\APP\pnpm` | `pnpm` | 解压后需确认 |
| `D:\Apps\VSCode\bin` | `code` 命令 | **实测不在 PATH**，所以 `code .` 会报找不到命令 |

添加方法：打开「编辑系统环境变量」→「环境变量」→ 在 **用户变量** 的 `Path` 里追加需要的目录。

> 验证：**关掉终端重新打开**再执行。若暂时不想配 PATH，可用全路径调用，例如：
> `& "D:\Apps\VSCode\bin\code.cmd" --version`

### 步骤 4：给 VS Code 装 ESLint 扩展（建议）

我没法替你装（沙箱限制），你在 VS Code 里操作更简单：

打开 VS Code → 按 `Ctrl+Shift+X` 打开扩展面板 → 搜索 **ESLint**（作者 Microsoft，ID `dbaeumer.vscode-eslint`）→ 安装。

项目已经配好 ESLint 规则，装上之后**写代码时就能实时看到违规提示**（比如「不许在 domain 层写魔法数字」）。

## 三、如果下载慢或超时（国内常见）

**npm / pnpm 换镜像**——编辑项目里的 `.npmrc`，把最后一行注释去掉：

```
registry=https://registry.npmmirror.com
```

**Git 走代理**（有代理软件的话，端口按自己的改）：

```powershell
git config --global http.proxy http://127.0.0.1:7890
git config --global https.proxy http://127.0.0.1:7890
```

> 实测提醒：我尝试自动下载 pnpm 独立版时，GitHub 直连被中断（ECONNRESET）两次。
> 遇到卡住别反复重试直连，**优先换镜像源**。
